# Intelecciones

Intelecciones es una plataforma integral de gestión y análisis electoral en tiempo real.

## Estructura del Proyecto

El repositorio está estructurado en las siguientes carpetas principales:

- [/backend](file:///c:/Users/Gustavo%20Quevedo/OneDrive/Dev/Intelecciones/backend): API servidor construida con Node.js, Express y SQLite.
- [/frontend](file:///c:/Users/Gustavo%20Quevedo/OneDrive/Dev/Intelecciones/frontend): Aplicación web SPA interactiva desarrollada en React, TypeScript y Vite.
